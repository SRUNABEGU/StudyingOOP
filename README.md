# Проект интернет-магазина

Проект представляет собой базовую логику управления товарами и категориями в интернет-магазине,\
реализованную на принципах объектно-ориентированного программирования (ООП) на Python.
---
### В проекте реализованы:
- Инкапсуляция: Защищенные атрибуты (цена, список товаров) с доступом через геттеры и сеттеры.
- Валидация: Проверка корректности цен и типов добавляемых товаров\
(в категорию можно добавить только объект класса Product или его наследников).

Проект покрыт тестами `Pytest` на **100%**.
